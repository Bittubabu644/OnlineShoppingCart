# 🛒 Online Shopping Cart

A full-stack online shopping cart web application built using **Python, Flask, HTML, CSS, and JavaScript**.

The application provides a shopping experience where users can browse products, search for products, explore different categories, view product details, add products to the cart, and proceed to checkout.

## 🚀 Features

- 🏠 User-friendly home page
- 🔍 Product search
- 📱 Product categories
  - Mobiles
  - Laptops
  - Accessories
  - Fashion
  - Home
  - Electronics
  - All Products
- 🛍️ Product listing
- 📦 Product details
- 🛒 Add to cart functionality
- 🧾 Shopping cart
- 💳 Checkout page
- 📊 Product information and specifications
- 📱 Responsive user interface
- ⚡ Flask-based backend

## 🛠️ Technologies Used
